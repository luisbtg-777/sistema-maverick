# Fitness MV · datos para Widgy
- `hoy.json` y `manana.json` se actualizan solos cada día a las 00:05 (CDMX).
- `dias/AAAA-MM-DD.json`: un archivo por día (17 nov 2026 → 6 ago 2028), generado desde el motor de la app.
- Campos listos para mostrar: `linea1` (fase · semana · día), `linea2` (rutina y horario), `linea3` (horarios ☕ 🥤 🍳 🍖 🐟 🔒), `linea4` (kcal · proteína · agua).
- Campos sueltos: fase, semana, rutina, cafe, pre, ventana.abre/cierra, comidas[], kcal, p, c, g, agua_l, app (link).
